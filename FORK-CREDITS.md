# T3 Mixed

T3 Mixed combines MT Code's agent workspace with the task-first board from T3 Kanban.

- T3 Code: https://github.com/pingdotgg/t3code
- MT Code: https://github.com/munimtechnologies/mtcode
- T3 Kanban: https://github.com/what1f/t3kanban

The Kanban board, task dialog, task details, task model, status icons and associated
tests were adapted from T3 Kanban. Task properties were ported to MT Code's V2
commands, event log, persisted projections and client state.
